# Primary technical sources

These official sources informed stack planning. Verify current compatibility during the build; documentation access does not establish execution or measured performance. Requested repository sources and hashes are separately in vendor/PROVENANCE.json.

- [React Three Fiber performance](https://r3f.docs.pmnd.rs/advanced/scaling-performance) — Instancing, reuse, adaptive quality, idle rendering; primary technical guidance.

- [Three.js InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html) — Repeated geometry and draw-call reduction.

- [Vite static deployment](https://vite.dev/guide/static-deploy.html) — Production build and Vercel handoff.

- [Zustand documentation](https://zustand.docs.pmnd.rs/) — Shared local store; verify current version compatibility.

- [Radix primitives](https://www.radix-ui.com/primitives/docs/overview/introduction) — Accessible unstyled controls.

- [Motion React](https://motion.dev/docs/react) — Interface motion implementation.

- [react-i18next hooks](https://react.i18next.com/latest/using-with-hooks) — Locale switching and translation resources.

- [Vitest guide](https://vitest.dev/guide/) — Deterministic unit/integration verification.

- [CadQuery documentation](https://cadquery.readthedocs.io/en/latest/) — Optional build-time modeling exploration.

The competition rules and concept provenance come from the supplied full competition/essay hub. Their inclusion is not a fresh official-rules verification or an essay submission audit. No external emissions coefficient or partner quote is used by the fixture model.
