# Design and interaction reconciliation

Reviewed 16 October 2026 against the approved brief, canonical token JSON, shared controls, implemented route flows, browser screenshots, and the installed frontend-design-premium 1.4.0 audit. This is a bounded implementation record, not an accessibility certification.

## Ownership and changes

`src/app/design-tokens.json` remains canonical (Model B). The former DESIGN.md referenced an input-package filename rather than the repository owner and lacked structured tokens. The revised document preserves its warm miniature-city direction, original-art rules, restrained operational density, and supplied-reference provenance. It adds a complete approved-token mirror and an explicit mapping to the maintained CSS adapter. `UX-CONTRACT.md` establishes cross-screen state/navigation/error responsibilities and names the actual native-select choice.

The token checker reads the source and mirror independently, checks the explicit semantic CSS mapping, and checks primary shared recipes. It does not rewrite tokens or treat screenshots as proof of token ownership. `premium-ui.json` points to real source roots and existing project tests; it does not disable scanning to hide a finding.

## Verification limits

The static audit does not prove accessible name quality, keyboard popup behavior on every OS, focus restoration under every route change, screen-reader output, mobile virtual-keyboard handling, 200% zoom, GPU performance, or real-world collection outcomes. Headless browser interaction checks and domain tests are separate evidence. See `docs/E2E_TESTING.md`, `docs/TEST_EVIDENCE.md`, and the independent critic report for their actual scopes.

## v1.2 refinement scan

The single current Impeccable scan (`IMPECCABLE_V12_SCAN.json`) targets the entire `src/` tree; its coverage is broader than the v1.1 entry-focused scan, so raw counts are not a quality trend. It found 700 items: 696 advisory type/material/radius differences and four primary warnings. The 3px accent on the tutorial formula was replaced with the shared 1px border. Plus Jakarta Sans and the warm cream palette remain the explicitly approved identity. The printable report's warning is a selector-context false positive: its 3px line belongs to a square report header; the radius belongs to an unrelated Print button. No rounded accent card exists there. The preserved world preview uses the approved warm background. The scan records the pre-correction observation; it was not rerun or suppressed to manufacture a clean result.

Partner roofs and badges now share `src/graphics/partner-styles.ts`. Their green, purple, clay and ochre materials identify reuse, components, material and specialist roles and include text; they do not replace action/status semantic tokens. Physical label occlusion and measured collision placement precede selection priority. Shared pause/speed and reduced motion cover city, hub and Team. The final Team geometry check includes neighboring names, roles and statuses as well as character images, so task captions cannot pass merely by avoiding image bounds.
