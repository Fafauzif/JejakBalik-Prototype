# Start here — JejakBalik 2.0

## Put it in an empty repository

1. Extract this ZIP.
2. Upload the **files and folders inside it** into your empty GitHub repository. `package.json` must be at repository root, alongside `src`, `public`, `api`, `server` and `vercel.json`.
3. In Vercel import the repository. Framework: **Vite**. Root: **.**. Build: **npm run build**. Output: **dist**. Node: **24**. Deploy and open `/network`.

The complete website works without AI setup. Start with **Ikuti perjalanan / Take the journey**. All five steps stay in Network and wait for you. The service model and optional device-review assistant are below the scene.

## Optional live AI — your USD1 budget

1. In OpenRouter create a dedicated key capped at **USD1 total**. Keep that key exclusive to this demo.
2. In your Vercel project add `OPENROUTER_API_KEY` and `AI_DEMO_ACCESS_CODE` as server environment variables. The demo code should be a random24+ character passphrase, distinct from the API key. Redeploy.
3. Open the optional review assistant, select live AI and enter the **demo code**, not the OpenRouter key. Test with the sample description. Local review always remains available.

Full instructions: `docs/AI_SETUP.md`. The provider key cap controls total model spend. Warm-instance request limits are supplemental. Vercel usage charges are separate. No real credentials are included.
