# Jejak Balik brand assets

Original return-path identity created for Jejak Balik, 16 October 2026. The open rounded path represents the journey back into use; the separate clay node marks a traceable point of origin. The left-facing turn expresses return without a generic recycling triangle.

## Approved assets
- `jejak-balik-horizontal-{forest,dark,light,reverse}.svg` — default lockup.
- `jejak-balik-stacked-*.svg`, `jejak-balik-mark-*.svg`, `jejak-balik-wordmark-*.svg`.
- Primary and reverse PNGs at 256, 512, 1024, 2048 pixel widths; mark at 32, 64, 128, 256, 512.
- `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` in public root.
- `tokens.json` preserves the approved warm-light palette.

All SVG wordmarks use editable vector outlines, so no font is required to render them. Text in the application and guide uses Plus Jakarta Sans. Font binaries and the SIL Open Font License are in `public/fonts`.

## Use
Use forest on cream and reverse on deep forest. Keep at least 8 units of clear space around a 64-unit mark (one stroke width). The standalone mark minimum is 20 CSS px; horizontal lockup minimum is 128 CSS px. For favicon at 16 px use the provided favicon, not a miniature wordmark.

Preserve proportions. Do not add shadows, gradients, boxes, or redraw the return path. Retain the clay origin node in primary versions. Use one-color versions when color is unavailable.

Household promise: **Penjemputan terjadwal, tanpa biaya.** Availability must be described by actual coverage; never imply instant nationwide service.
